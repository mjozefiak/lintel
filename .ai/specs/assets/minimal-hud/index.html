The pill family

One capsule, one height (32 pt at M, 28 at S, 38 at XL), glass, at most one text button plus ✕, one line of text. Glyphs: live = the Lintel ring turning (meeting: with the breathing centre dot; dictation: without), working = the ring closing, problem = amber ⚠, failed = red ⚠, done = ✓ in the live colour.
